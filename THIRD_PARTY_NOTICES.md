# Third-party notice policy

This source-tree policy file is not a release notice bundle. The exact
`THIRD_PARTY_NOTICES.md` distributed with a DAS Leafer release is generated by
`scripts/release/build_release_artifacts.py` from the reviewed, exact-version
decisions in `release/dependency_license_decisions.json`. The build fails for
an unknown, denied, extra, or unpinned dependency.

Do not attach this policy file to a GitHub or Python-package release as its
third-party notice artifact.
